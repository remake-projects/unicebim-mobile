# legacy-web

Bu klasör, mobil porta başlamadan önceki **Next.js web uygulamasının** dondurulmuş kopyasıdır
(aynı içerik git etiketi `web-baseline` = `bbcd95e` altında da duruyor).

- Çalıştırılmaz, build/test/lint kapsamı dışındadır.
- Port sırasında davranışı referans almak için tutulur.
- Web'e geri aktarılacak değişikliklerin listesi: `docs/mobil-port-analizi.md` §9.
- Port tamamlanınca bu klasör silinebilir; web'in yaşayan kopyası orijinal repodadır.
